# ResumeMatch AI v0.4 — семантическое сопоставление

Это **добавочное обновление** для рабочей версии v0.3 в `F:\MATRIX`. Оно не заменяет уже подключённые `app/llm.py`, `app/llm_api.py`, `app/llm_matching.py` и `app/llm_match_api.py`.

## Содержимое архива

- `app/llm_semantic.py` — отдельный шаг LLM: оценивает смысловое сходство только там, где точных совпадений нет. Модель выбирает ID подтверждённых цитат и объясняет вывод; Python не принимает выдуманные ID и не подставляет сгенерированные «цитаты».
- `app/llm_semantic_api.py` — `POST /api/llm/semantic-match` с отдельным согласием.
- `static/index.html` — выбор вакансии, дополнительная кнопка семантического анализа, расширенный адаптивный интерфейс, раскрываемые доказательства.
- `tests/test_llm_semantic.py` — офлайн-тесты с подставной моделью; не расходуют токены.

Архив не содержит `.env`, API-ключей, `main.py`, окружения `.venv` и пользовательских документов.

## Установка в F:\MATRIX

1. Останови сервер (`Ctrl+C`).
2. В PowerShell сделай резервную копию текущего интерфейса и API:

```powershell
cd F:\MATRIX
Copy-Item .\static\index.html .\static\index.v03.backup.html
Copy-Item .\app\main.py .\app\main.v03.backup.py
```

3. Распакуй **содержимое** архива в `F:\MATRIX` (замени только `static/index.html`; остальные 3 файла — новые).
4. Открой `app/main.py`. В раздел с другими импортами добавь:

```python
from .llm_semantic_api import router as llm_semantic_router
```

5. Сразу после `app = FastAPI(...)`, рядом с `app.include_router(llm_router)` и `app.include_router(llm_match_router)` добавь:

```python
app.include_router(llm_semantic_router)
```

6. Убедись, что `openai`, `python-dotenv`, `fastapi`, `pytest` уже установлены (они используются в v0.3). Проверки:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8765
```

7. Открой `http://127.0.0.1:8765/docs` и найди новый `POST /api/llm/semantic-match`. Затем открой `http://127.0.0.1:8765` и нажми `Ctrl+F5`. Если интерфейс выглядит очень мелким, нажми `Ctrl+0` для сброса масштаба браузера.

## Как проверить на UI

1. Загрузи `samples/demo_resume.txt` и нажми «Проанализировать резюме».
2. В блоке **LLM-анализ OpenAI** выбери вакансию **Backend-разработчик Django** (у неё могут быть непокрытые навыки Redis/Celery).
3. Поставь галочку и нажми «Извлечь данные через OpenAI». Выполнится два платных запроса (резюме, вакансия); отобразится старая матрица v0.3.
4. Отдельно разреши отправку уже извлечённых цитат и нажми **«Проверить смысловые совпадения (OpenAI)»**. Если остались непроверенные требования/стаж и есть источники, выполняется ещё один тарифицируемый запрос.
5. Сравни: **процент по точным совпадениям** и **предварительный процент с предложениями LLM**. Раскрой доказательства по каждой строке. Стаж и частичные совпадения не входят в процент.
6. Нажми «Скачать полный JSON»: данные `latest.llm.semantic` включены в экспорт после семантического анализа.

## Гарантии и ограничения

- Старый `POST /api/llm/match` остаётся полностью локальным и бесплатным; **никаких новых платных вызовов автоматически не возникает**.
- LLM-совпадения — предложения для ручной проверки, **не** автоматически подтверждённый опыт, а предварительный процент — не вероятность трудоустройства.
- `source_verified` был вычислен при первоначальном извлечении; endpoint `/semantic-match` не открывает оригиналы файлов заново. Для модели предоставляются лишь факты с таким флагом и их цитаты, но тот, кто вызывает API напрямую, технически может подделать этот флаг. Для строгой доказательной приёмки следующий этап — хранить подтверждённые блоки на сервере в пределах сессии и сверять их по исходному документу.
- Модель не может подменить текст цитаты или добавить выдуманный `evidence_id`: Python выводит только исходные цитаты с известными ID. Но модель всё ещё может ошибиться **в смысловой оценке**.
- На этом этапе нет отдельной векторной базы, эмбеддингов или FAISS; «семантическая проверка» означает **LLM-анализ фрагментов текста**, а не векторный поиск. Для полноценного RAG по большим документам добавим retrieval позже.
- Прямой запуск тестов без ключа не вызывает OpenAI. Реальный вызов в твоей среде требует действующего `.env` и тарифицируется провайдером.
