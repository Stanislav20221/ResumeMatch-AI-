# ResumeMatch AI v0.8 — итоговый отчёт и PDF

**Цель:** превратить доказательную матрицу v0.7 в читаемый отчёт для ручной оценки требований вакансии. Отчёт **не** является автоматическим решением о найме.

## Что добавлено

- `POST /api/report/preview` — JSON-предпросмотр с нейтральным заключением, счётчиками и доказательной матрицей.
- `POST /api/report/pdf` — PDF A4 на русском языке: сводка, обязательные/желательные навыки, стаж, обязанности, RAG-наблюдения, цитаты и ограничения.
- Раздел **«Итоговый отчёт по кандидату · v0.8»** в интерфейсе с кнопками предпросмотра и скачивания.
- Генерация PDF через `reportlab` и системные TTF-шрифты (`Arial` или `Segoe UI` в Windows), без включения файлов шрифтов в архив.
- **Без новых запросов к OpenAI**: оба маршрута повторно вызывают `build_evidence_matrix` по исходному резюме и вакансии. Готовая матрица JSON из браузера не принимается на доверии.
- Результат не записывается в базу или на диск сервера. PDF содержит цитаты и при наличии персональные данные: относись к нему как к конфиденциальному документу.

## Установка в PowerShell

**Перед установкой:** рабочая v0.7 уже опубликована на GitHub. Убедись, что текущие изменения сохранены.

1. Распакуй содержимое `ResumeMatch_AI_Report_PDF_v0.8.zip` в `F:\MATRIX` с сохранением папок `app`, `scripts`, `assets`, `tests`. Новые файлы не должны перезаписать модули v0.7.
2. Выполни:

```powershell
cd F:\MATRIX
.\.venv\Scripts\python.exe scripts\install_report_v08.py
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pytest -q
```

Установщик внесёт точечные изменения в `app/main.py`, `static/index.html`, `requirements.txt`, `.gitignore`, `README.md` и создаст копии `*.before_report_v08`, исключённые из Git. Его можно запускать повторно: разделы и маршруты не дублируются.

3. Запусти сервер:

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8765
```

Проверь `/docs` — должны быть `POST /api/report/preview` и `POST /api/report/pdf`.

## Проверка в интерфейсе

1. Открой http://127.0.0.1:8765 и обнови страницу `Ctrl+F5`.
2. Загрузи `samples/demo_resume_experience_positive.txt`, режим «Демо», количество вакансий — 5.
3. Выбери «Python Backend / AI-разработчик — проверка стажа».
4. Выполни LLM-извлечение для выбранной вакансии. Для содержательного отчёта также запусти анализ стажа (отдельный запрос к OpenAI, требующий согласия); RAG/семантика необязательны.
5. Нажми **«Предпросмотр отчёта»**: появятся счётчики и итоговое заключение.
6. Нажми **«Скачать отчёт PDF»** и открой файл локально. Проверь русские буквы, переносы, отображение цитат и номера страниц.

Сам экспорт отчёта **не** требует дополнительного согласия на облачную обработку, так как с сервера не выполняются новые OpenAI-запросы.

## Ограничения

- Процент — **только доля дословных упоминаний обязательных навыков**. Это не общий балл квалификации и не вероятность трудоустройства.
- «Предварительно достаточно по стажу» не означает юридически или кадрово подтверждённый опыт: связь технологий с местами работы, даты и цитаты требуют проверки.
- Предложения LLM, RAG и смысловые совпадения — **поводы для проверки**, не доказанные факты.
- «Нет подтверждения» не означает, что кандидат не владеет навыком.
- Отчёт содержит данные резюме и вакансии. Не публикуй PDF в Git и не передавай без разрешения кандидата.
- Предпросмотр и PDF формируются из оригинальных документов текущего запроса; отчёт не доверяет клиентскому «проверено».
