# ResumeMatch AI v0.5 — стаж, даты и обязанности с цитатами

Это **дополнение к работающей v0.4**, а не новая версия проекта с нуля.
Обновление не содержит `.env`, OpenAI API-ключей и виртуального окружения.

## Изменения

- Новый `app/llm_experience.py`: отдельный платный OpenAI-анализ датированных мест работы, обязанностей и использованных технологий.
- Новый `app/llm_experience_api.py`: endpoint `POST /api/llm/experience-match` с загрузкой исходного резюме и проверкой согласия.
- Обновлённый `static/index.html`: новый раздел «Опыт работы, сроки и обязанности», отдельные согласие и кнопка.
- Новый офлайн-тест `tests/test_llm_experience.py` (14 тестов).
- Синтетическое резюме с датами `samples/demo_resume_dated.txt` и пример вакансии `samples/demo_vacancy_experience.json`.

## Установка в F:\MATRIX — Windows PowerShell

1. Останови Uvicorn (`Ctrl+C`).
2. Сохрани резервные копии:

```powershell
cd F:\MATRIX
Copy-Item .\static\index.html .\static\index.v04.backup.html
Copy-Item .\app\main.py .\app\main.v04.backup.py
```

3. Распакуй архив **в корень `F:\MATRIX`**, сохраняя вложенные папки `app`, `static`, `tests`, `samples`. Из существующих файлов замещается **только `static/index.html`**. Если ты ранее менял HTML вручную, сначала сравни версии.
4. В `app/main.py` добавь импорт рядом с другими роутерами:

```python
from .llm_experience_api import router as llm_experience_router
```

А **после объявления `app = FastAPI(...)`** добавь:

```python
app.include_router(llm_experience_router)
```

Не удаляй прежние роутеры `llm_router`, `llm_match_router`, `llm_semantic_router`.

5. Проверка **без платных запросов**:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -c "from app.llm_experience_api import router; print('EXPERIENCE ROUTER OK')"
```

6. Запуск на уже работающем порту:

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8765
```

Открой: http://127.0.0.1:8765 и Swagger http://127.0.0.1:8765/docs.

В документации должен появиться `POST /api/llm/experience-match`.

## Проверка в интерфейсе

1. Загрузи **`samples/demo_resume_dated.txt`** (вымышленные данные).
2. Выбери демо-вакансию либо реальную вакансию hh.ru, выполни обычный анализ.
3. В разделе OpenAI выбери вакансию, согласись на отправку данных и нажми «Извлечь данные через OpenAI».
4. В новом разделе «Опыт работы, сроки и обязанности» поставь **отдельную** галочку согласия.
5. Нажми «Проверить стаж и обязанности (OpenAI)».

Будет выполнен **1 платный запрос** на извлечение опыта и **второй платный запрос, только если** в вакансии есть обязанности и в резюме найдены подтверждённые задачи.

В демо-вакансиях v0.4 не всегда присутствуют явные требования к длительности опыта и обязанности; в таком случае одноимённые блоки будут пустыми — это ожидаемо, а не ошибка. Для проверки расширенного сценария подойдёт вакансия с текстом вида `Опыт работы с FastAPI от 2 лет` и `Разрабатывать REST API`. Пример находится в `samples/demo_vacancy_experience.json`.

## Что означает результат

- `dates_verified`: исходная цитата содержит явно указанные нормализованные месяц и год, роль тоже найдена в резюме.
- `source_verified`: строка-цитата присутствует в тексте повторно загруженного резюме или, для требований вакансии, в предоставленном исходном тексте вакансии.
- `documented_months_total_conservative`: сумма непересекающихся интервалов подтверждённых месяцев; завершающий месяц не учитывается.
- `status=duration_meets_provisionally`: по **документированным** периодам достаточная длительность, но назначение навыка к должности предлагает LLM, и человек должен это проверить.
- `responsibility_reviews`: предложения модели по обязанностям с цитатами, без автоматической финальной оценки.
- Прежний процент совпадения **не изменяется** и всё ещё относится только к навыкам.

Система не делает предположений о месяце для года вида `2022–2024`. Модели не разрешается ссылаться на несуществующие `evidence_id`. Цитата подтверждает факт наличия текста, но не истинность интерпретации. Извлечённые работа и период могут относиться к разным разделам резюме — потому **ручная проверка обязательна**.

## Конфиденциальность и стоимость

Резюме направляется в OpenAI **только после отдельного согласия**; данные не сохраняются в базе. Строки с очевидными email не включаются в запрос v0.5, но **имена и другие персональные данные могут передаваться**. Используй синтетическое резюме для первого теста. Ключ берётся на сервере из `.env`; `store=False` передаётся во все вызовы OpenAI. Обработка через API оплачивается по тарифам аккаунта.

## Если возникают ошибки

- `422`: проверить согласие, формат файла и содержимое JSON вакансии.
- `502`: ошибка внешнего OpenAI API, например неверный ключ или превышен лимит.
- Пустая хронология: в резюме нет явно описанного опыта или модель не смогла его достоверно извлечь.
- Нет длительности: отсутствуют месяцы, цитаты не подтверждены или модель не связала должность с датами.
- Если новый блок интерфейса не виден: обновить страницу `Ctrl+F5`.
