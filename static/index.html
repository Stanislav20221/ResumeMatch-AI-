От резюме к матрице
соответствия вакансии

Загрузите резюме, получите структурированный JSON и сравните навыки с требованиями вакансий. При необходимости включите OpenAI-анализ с подтверждающими фрагментами исходного текста.

Новый анализ

PDF с текстовым слоем, DOCX или TXT (UTF-8), до 6 МБ. Для сканированных PDF можно включить локальный OCR.
В базовом режиме резюме обрабатывается локально и не отправляется в OpenAI.

—Навыков распознано в резюме
—Вакансий обработано

Векторный поиск и RAG · FAISS

Эмбеддинги OpenAI → временный FAISS-индекс → поиск по фрагментам → ответ LLM с проверенными дословными цитатами. Новые платные запросы выполняются только после согласия.

Индекс хранится в оперативной памяти сервера до 20 минут, не сохраняется на диск.

FAISS возвращает семантически близкие фрагменты, но сходство не доказывает выполнение требований. Сервер подтверждает дословные цитаты; выводы LLM требуют ручной проверки.

Пакетное сравнение резюме · v0.9

Одна вакансия — до пяти резюме. Система сопоставляет проверяемые цитаты и показывает отдельные матрицы. Не ранжирует кандидатов и не принимает кадровых решений.

Сначала выполни обычный анализ в форме выше, чтобы загрузить вакансии.

Максимум пять файлов. Они не сохраняются в базе и используются только для текущего анализа.

Обработка идёт по очереди. Единая матрица собирается локально без дополнительных API-вызовов.

Доли дословных упоминаний не означают качество кандидата. Неподтверждённые сведения требуют ручной проверки. Полноценный RAG по каждому резюме отдельно в этом режиме не запускается.

Семантическое сопоставление · OpenAI

            

              Для требований без точного совпадения модель ищет смысловые доказательства
              в подтверждённых цитатах резюме. Результат — предложение для проверки человеком,
              а не окончательная оценка. Стаж выводится отдельно и не включается в процент.

Опыт работы, сроки и обязанности · OpenAI

            

              Повторно читаем исходное резюме, извлекаем датированные места работы,
              сверяем дословные цитаты и сравниваем обязанности с выбранной вакансией.
              Сроки без точного месяца и года не подсчитываются. Итоги требуют проверки человеком.

Единая доказательная матрица · v0.7

            
Объединяет навыки, стаж, обязанности и RAG-цитаты. Формируется локально по исходным документам без дополнительных запросов и оплаты OpenAI. Недоказанные и предварительные выводы остаются видимыми отдельно.

            

              
              Можно запускать после LLM-извлечения; предварительные выводы добавятся после семантического анализа, проверки стажа и RAG.
            

            

            

          

          
          
          

            
Итоговый отчёт по кандидату · v0.8

            
Собирает проверяемую матрицу заново, показывает нейтральное заключение и создаёт PDF с цитатами. Это не оценка пригодности к найму. Отчёт формируется локально, без дополнительных запросов к OpenAI.
