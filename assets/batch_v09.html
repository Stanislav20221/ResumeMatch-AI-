Пакетное сравнение резюме · v0.9

Одна вакансия — до пяти резюме. Система сопоставляет проверяемые цитаты и показывает отдельные матрицы. Не ранжирует кандидатов и не принимает кадровых решений.

Сначала выполни обычный анализ в форме выше, чтобы загрузить вакансии.

Максимум пять файлов. Они не сохраняются в базе и используются только для текущего анализа.

Обработка идёт по очереди. Единая матрица собирается локально без дополнительных API-вызовов.

Доли дословных упоминаний не означают качество кандидата. Неподтверждённые сведения требуют ручной проверки. Полноценный RAG по каждому резюме отдельно в этом режиме не запускается.
