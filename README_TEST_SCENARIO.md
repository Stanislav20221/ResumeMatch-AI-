# ResumeMatch AI v0.5 — тестовая вакансия с требованиями к стажу

Это **не замена приложения**, а точечное обновление только демонстрационных данных и новый офлайн-тест.
Оно не затрагивает `.env`, OpenAI-ключ, интерфейс, `app/llm.py`, `app/llm_experience.py` или `app/main.py`.

## Установка на Windows

1. Останови Uvicorn (`Ctrl+C`).
2. В корне `F:\MATRIX` сделай резервную копию `app\demo.py`:

   `Copy-Item .\app\demo.py .\app\demo.before_experience_demo.py`

3. Распакуй содержимое ZIP **в корень `F:\MATRIX`**, чтобы файлы попали в `app\demo.py`, `samples\demo_resume_experience_positive.txt` и `tests\test_demo_experience_vacancy.py`. Разреши замену **только** `app\demo.py`.
4. Проверь файлы: `Test-Path .\app\demo.py` и `Test-Path .\samples\demo_resume_experience_positive.txt`.
5. Запусти офлайн-тесты:

   `.\.venv\Scripts\python.exe -m pytest -q tests/test_demo_experience_vacancy.py`

   `.\.venv\Scripts\python.exe -m pytest -q`

6. Запусти сервер:

   `.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8765`

7. Открой главную страницу. Выбери `Демо`, **количество 5** (не 3), загрузи `samples/demo_resume_experience_positive.txt`, нажми «Проанализировать резюме».
8. Найди вакансию **«Python Backend / AI-разработчик — проверка стажа»** (карточки сортируются по совпадению, поэтому позиция может меняться), а затем нажми «Извлечь данные через OpenAI» с явным согласием.
9. Убедись, что в JSON вакансии раздел `fields.experience` содержит два требования к стажу, а `fields.responsibilities` — две обязанности. Если LLM что-то пропустила, перепроверь извлечение до сравнения.
10. Отдельно согласись на дополнительный запрос в разделе «Опыт работы, сроки и обязанности» и нажми «Проверить стаж и обязанности (OpenAI)». Это **платный** API-запрос.

## Что должно проверяться

- Python >= 3 лет -> `required_months=36`, по явно привязанному опыту первой должности `documented_months=40`, статус **предварительно достаточно**.
- FastAPI >= 2 лет -> `required_months=24`, подтверждённых месяцев по первой должности — `40`, статус **предварительно достаточно**.
- Обязанности REST API и интеграция LLM должны появиться для LLM-сопоставления с цитатами. Их вывод предварительный.
- Общий стаж по двум местам: 57 непересекающихся месяцев, при принятом в v0.5 исключении конечного месяца.
- Навык Kubernetes не указан в резюме; наличие у кандидата нельзя утверждать и нельзя отрицать.

**Важно:** расчёт стажа по технологиям зависит от корректности извлечения LLM, привязки технологии к конкретной работе и подтверждающих цитат. Он не должен автоматически менять процент соответствия навыков. Все результаты требуют проверки человеком. Если протестировать прежнее `samples/demo_resume_dated.txt`, в его работе Python явно не назван: ожидаем «недостаточно данных» о 3-летнем Python-стаже, а не выдуманную длительность.
