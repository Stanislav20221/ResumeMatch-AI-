# ResumeMatch AI v0.7 — единая доказательная матрица

## Что добавлено

Новый локальный API **`POST /api/evidence/matrix`** и раздел **«Единая доказательная матрица · v0.7»** после модулей v0.3–v0.6.1.

Матрица объединяет:

1. **Обязательные и желательные навыки** из структурированных OpenAI JSON, включая восстановленные явные перечисления. Прямое совпадение — только факт *упоминания*, не подтверждение квалификации.
2. **Семантические предложения LLM**, если этап v0.4 запускался: только с цитатами из оригинального резюме, не меняют подтверждённый процент.
3. **Числовые требования к стажу** из v0.5: локально заново проверяются даты и цитаты по загруженному резюме, исключаются пересечения, явно указывается требуемое и документированное количество месяцев. Связь технологии с местом работы остаётся предметом ручной проверки.
4. **Сопоставление обязанностей** из v0.5: проверяемые цитаты резюме и вакансии, статусы LLM — только предварительные.
5. **RAG-наблюдения** из v0.6.1, если для *той же* вакансии выполнен «Спросить RAG»: цитаты заново сверяются по оригиналам, наблюдения выводятся отдельно и не начисляют баллы.

**Новый этап не вызывает OpenAI и не требует дополнительного согласия на облачный запрос.** Документ загружается только на локальный FastAPI сервер для повторной сверки. Другие платные LLM/embedding-этапы продолжают требовать отдельного согласия.

## Установка на Windows (F:\MATRIX)

1. **Сохрани текущую работающую версию в Git** (v0.6.1). Не выполняй push до успешных проверок v0.7.
2. Распакуй содержимое `ResumeMatch_AI_Evidence_Matrix_v0.7.zip` **в `F:\MATRIX`** с сохранением структуры. Добавляются новые `app/evidence_matrix.py`, `app/evidence_matrix_api.py`, `tests/test_evidence_matrix.py`, `scripts/install_evidence_v07.py`, `assets/evidence.*`, `README_EVIDENCE_v0.7.md`. Старые Python/HTML файлы пока не заменяются.
3. Выполни в PowerShell:

```powershell
cd F:\MATRIX
.\.venv\Scripts\python.exe scripts\install_evidence_v07.py
.\.venv\Scripts\python.exe -m pytest -q
```

Установщик самостоятельно добавляет два Python-маркера в `app/main.py`, один UI-раздел в `static/index.html` и клиентский сбор результатов, а также исключает свои резервные копии из Git. Копии оригиналов: `app/main.py.before_evidence_v07`, `static/index.html.before_evidence_v07`.

4. Если тесты прошли, запусти:

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8765
```

Открой http://127.0.0.1:8765. Проверь `/docs` — там должен появиться **`POST /api/evidence/matrix`**.

## Сквозной сценарий

1. Загрузи `samples/demo_resume_experience_positive.txt`, режим «Демо», 5 вакансий.
2. Выбери **«Python Backend / AI-разработчик — проверка стажа»** и запусти LLM-извлечение.
3. Сразу после LLM-анализа можно нажать «Собрать единую матрицу»: будут доступны навыки; стаж и обязанности получат статус **«Проверка не запускалась»**.
4. Запусти v0.5 «Проверить стаж и обязанности (OpenAI)» (тарифицируемый запрос); затем снова собери матрицу. Должны появиться числовые показатели стажа и предварительные сопоставления задач.
5. При желании отдельно запусти семантическое сопоставление v0.4 и RAG v0.6.1 для **той же вакансии** (дополнительные тарифицируемые запросы). После каждого этапа нажимай «Собрать единую матрицу».
6. Раскрой «Исходные подтверждения и методы» в каждой строке — увидишь цитату вакансии, цитаты резюме и способ проверки.

## Пример результата

| Требование | Возможный статус | Основание |
|---|---|---|
| Python (навык) | Дословно упомянуто | Цитата навыков из резюме |
| FastAPI от 2 лет | Стаж предварительно достаточен | Даты + технология в датированной записи; 24 / 40 месяцев в демонстрационном сценарии |
| REST API | Предложение LLM | Проверенная цитата выполненной задачи |
| Kubernetes | Не подтверждено | Отсутствует проверяемое положительное подтверждение |

Стажа **40 месяцев** для FastAPI ожидаем только если LLM v0.5 верно извлекла даты и связала технологию с работой. Конкретные результаты облачной модели могут отличаться; это не жёсткая гарантия.

## Важные ограничения

- Совпадение текста доказывает лишь **наличие цитаты в исходном документе**, не истинность профессионального утверждения.
- RAG и семантические выводы проверяются человеком; предложение LLM **не является доказанным совпадением** и не увеличивает процент.
- При недостатке данных статус **«недостаточно данных»** или **«проверка не запускалась»**, а не отрицательный вывод о кандидате.
- Процент в v0.7 — только доля буквальных упоминаний обязательных навыков, не итоговая квалификация и не вероятность найма.
- Файлы и индекс не сохраняются в базе. Все этапы, в которых текст уходит в OpenAI, должны выполняться с согласия пользователя. v0.7 само по себе не обращается к OpenAI.
- Резюме и цитаты отправляются локальному FastAPI на `127.0.0.1`. Не публикуй локальный сервис без аутентификации и защиты персональных данных.
